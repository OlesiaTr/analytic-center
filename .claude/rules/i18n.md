# Languages (uk / en)

- Ukrainian at `/`, English at `/en` (next-intl, `localePrefix: 'as-needed'`, no
  locale detection). Routing lives in `src/i18n/`.
- UI labels go in `messages/{uk,en}.json` with the same keys and ICU arguments
  in both (`src/i18n/messages.test.ts` checks). Counts are ICU plurals, never
  string building. Content is never in messages: it lives in Sanity.
- Internal links use `Link` / `usePathname` / `getPathname` from
  `@/i18n/navigation`, so `/grants` becomes `/en/grants` on English pages.
  `usePathname` returns the path without the locale.
- Dates and sorting take the locale (`useLocale()` / `getLocale()`), never a
  hard-coded `'uk'`.
- Content with no English falls back to Ukrainian: queries return `lang` and the
  component sets it on the element (`lang="uk"` on /en) for screen readers and
  search engines.
- `ENGLISH_PUBLIC` in `src/constants/features.ts` gates the language switch, /en
  indexing, hreflang and the sitemap. /en works either way.
- English content is translated with the `translate` skill and lands as Sanity
  drafts for an editor to publish.
